# Data folder

Place `Reviews.csv` (Amazon Fine Food Reviews) here before running
`train_and_export_models.py`. The file is intentionally **not** committed
to git (see `.gitignore`) — GitHub's normal upload rejects files over
100MB, and Reviews.csv is around 300MB.

If you want the dataset itself visible on GitHub for grading, either:
- link to the Kaggle/SNAP source in your README instead of uploading it, or
- use [Git LFS](https://git-lfs.com/) to track it.
